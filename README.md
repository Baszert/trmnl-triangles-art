# Triangles

A randomly generated artwork of triangles on every refresh. Inspired by Japanese Kumiko woodwork, but more random.

<a href="https://trmnl.com/recipes/220720"><img width="150" alt="Works with TRMNL" src="https://trmnl.com/images/brand/badges/light/works-with-trmnl/trmnl-badge-works-with-light.svg" /></a>

## Settings
- **Columns:** 4–50 (default 8)
- **Stroke width:** 2–50 (default 10)
- **Border width:** 2–50 (default 10)
- **Emptyness:** 0–10, how much whitespace (default 5)

### Develop locally

Templates and settings live in [`src/`](src/), ready for [trmnlp](https://github.com/usetrmnl/trmnlp):

```sh
gem install trmnl_preview
trmnlp serve
```
